Technical
DevOps, Docker, HTTPS, Nginx

上一篇把 API 镜像推送到了 Docker Hub。这一篇转到 Ubuntu VPS：拉取镜像，运行 API 和 PostgreSQL，再让 Nginx 接管公网流量和 HTTPS。

一、前置条件与 Docker

开始前需要准备：

  • Ubuntu LTS VPS 与 sudo 权限
  • 已指向 VPS 的域名（示例 api.example.com）
  • 已开放 TCP 80/443
  • Docker Hub 私有镜像
  • API 的 GET /health 健康检查端点

Let’s Encrypt 不为裸 IP 签发这里使用的普通 HTTPS 证书。域名必须正确解析到 VPS，公网也要能访问 80 端口，HTTP-01 验证才能通过。

安装 Docker 前，先按照 Docker Engine 在 Ubuntu 上使用官方仓库安装 配置 Docker 官方 apt 仓库。Ubuntu 默认软件源不包含 Docker CE，直接执行 apt install docker-ce 通常会看到 Unable to locate package。
